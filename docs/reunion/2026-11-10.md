## 3- Gameplay et systèmes de pouvoir

### Système de pouvoir :

**Inspirations** : FMAB, WHA

**Nom** : Aupération

**Formule + charge + matière = opération**

#### 3 Règles

1. Rien ne se crée
2. Chaque rune a ses matières
3. Ce qu’on apprend, on le garde

#### 4 runes

- Déplacer o->
- Transformer 𝔻
- Relier Ꚙ
- Produire ✧

### Gameplay :

Class :

| Aupérateur | Paladin | Chevalier |
|---|---|---|
| Pas d’arme lourde | Manipulation de toutes les armes | Manipulation de toutes les armes |
| Rapidité d’opérations élevée | Rapidité d’opération faible | Vitesse d’exécution élevée |
| Nombre de sorts élevés | Nombre de sorts limités | Défense moyenne |
| Capacité physique limitée | Capacité physique moyenne | Possibilité d’utiliser les artefacts |
 
### Mécaniques :

- Esquive : Possibilité de contre-attaquer, augmenter les dégâts.
- Soutien : Pour booster les capacités du héros.
- Contre-artefact
